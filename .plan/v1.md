# newsdesk 第 1 版：可上线的私人资讯解读站

## Context

用户把产品/技术方案（`CLAUDE.md`）放进了新项目 `/Users/derek/code/newsdesk`，要求不再逐步确认，直接交付一个**可上线的 web 站**，发到 GitHub（公开即可）。第 0 步（手工事件卡）的调研已完成，底稿在 `docs/step0/worksheet-fomc-2026-09-16.md`；本计划把它变成种子内容，并按文档「第 1 版」范围建流水线 + 静态站 + 部署。

调研结论（决定了下面的选型）：

- **LLM 调用**：环境里没有 `ANTHROPIC_API_KEY`；`claude -p --output-format json` 在剥掉本会话的 `ANTHROPIC_AUTH_TOKEN/ANTHROPIC_BASE_URL` 后能用订阅额度跑通。→ LLM 层做双后端：有 API key 走 SDK，否则走 `claude -p`（默认）。
- **L1 源可达性**：美联储 RSS ✅（`press_monetary.xml`，含 9/16 声明）；BLS 网页全部 403，但 **API v2 无 key 可用** ✅；人民银行栏目页 HTML 可抓 ✅；gov.cn 政策库返回 124 字节反爬页 ✗、stats.gov.cn RSS 空 ✗、SEC EDGAR atom 403 ✗ → 第 2 版再接。
- **媒体 RSS 可用 8 个**：BBC Business、Guardian Business、NYT Business、CNBC Finance、MarketWatch、Al Jazeera、界面新闻、Economist Finance。人民网财经 RSS 停更于 2025-06 ✗，经济观察网 RSS 空 ✗。
- **GitHub**：`gh` 已登录 `derek2035`，无 `derek2035.github.io`，两个旧 blog 仓库均未开 Pages、10 年没动。→ 新建公开仓库 `derek2035/newsdesk`，Pages 从 `gh-pages` 分支发布。
- Python 3.12 + uv 可用；feedparser/trafilatura/jinja2/anthropic/numpy 均未装 → uv 建 venv。

## 范围（第 1 版，按文档）

做：3 个 L1 源 + 8 个媒体 RSS；无聚类；每个 L1 文档 = 一个事件；规则分级；四段解读只出 E1/E2；三道闸门；静态站三页（今日流、事件卡、归档搜索）；launchd 每日跑；原子发布到 GitHub Pages。
不做：跨语言聚类、GDELT 落差、「被低估」栏、cross-encoder 蕴含判定（用「逐字引文 + 数字回填」代替）、访问控制（用户明确说公开即可）。

## 实施步骤

### 1. 脚手架 + 数据模型
- `uv init` + 依赖；`db.py` 建表：`source, document, passage, event, event_scope, event_member, interpretation, claim, citation, generation_log`（`generation_log` 从第一天就存 model/prompt_version/输入快照 hash）。
- `config/sources.yaml` 登记 11 个源；`display_policy`：L1=full，媒体=title_only（公开站，比文档的 100 字摘要更保守）。

### 2. 抓取器（3 个 L1 + RSS 通用）
- `rss.py`：feedparser 通用，媒体源只写 document 行，不落正文。
- `fed.py`：RSS 发现 → 抓 `monetary*.htm` → 提取 `<p>` 段落为 passage（已验证结构干净）；FOMC 声明额外抓同日 implementation note 与上一份声明作为「上一版文件」。
- `bls.py`：API v2 拉 CPI（CUUR0000SA0/SA0L1E/SA0E）与非农（CES0000000001/LNS14000000）；`latest=true` 的 period 变化 = 新发布事件；passage 由数据生成为规范句子（「8 月 CPI-U 指数 334.980，同比 +3.4%」），数据即证据。
- `pboc.py`：人民银行「新闻/公开市场业务公告」栏目页 HTML → 标题/链接/日期 → 正文段落（trafilatura）。
- 每个 L1 抓取器一份 golden file + pytest。

### 3. 解析器与分级（规则，不调模型）
- `fed_rate.py`：从声明正则出目标区间、变动 bp、投票；人口=FRED POPTHM 固定值、行业=11、经济规模=美国 GDP、持续时间=上一次同类间隔；等级：变动≠0 或方向反转 → A，维持 → B，其他 Fed 稿 → C。
- `econ_data.py`：CPI/非农 → B；`default.py` → C，保守估计。
- 等级只升不降（重跑时取 max）。

### 4. 解读 + 三道闸门
- `interpret.py`：输入带编号段落（本事件 + 上一版 + 结构数据），固定 system prompt 要求输出 `{sections:{what,changed,magnitude,divergence}, claims:[{text, evidence:"E1"|"E2", passages:[id], quote, formula?}]}`；模型映射 A→`claude-fable-5-1`、B→`claude-opus-5`、C→`claude-sonnet-5`；`claude -p --model X --output-format json`，温度不可控时靠 schema 约束 + 校验兜底（README 注明）。
- `gates.py`：① JSON/schema/evidence 枚举 ② 每条 claim 的 `quote` 必须逐字存在于所引 passage（归一化空白、全半角） ③ claim 文本里所有数字（含 `3-3/4`→`3.75`、`1/4 percentage point`→`25bp`、`%`）必须能在被引 passage 中找到；E2 需 `formula` 且计算值可复算。失败整条丢弃，丢弃率写入 `generation_log`。

### 5. 静态站
- `build.py` + Jinja2：`index.html`（按时间排列 + 页底「未达 C 级 N 条」折叠）、`events/<id>.html`（卡片结构 1–7：可信度标/等级标、中性标题、范围四数（持续时间标「估计」）、信源条（L1 优先，媒体按关键词重合挂到事件，转载折叠）、一句话事实、AI 区块带署名头+生成时间、结论角标悬停显示原文片段）、`archive.html`（预生成 `index.json`，原生 JS 客户端搜索/筛选）。
- `robots.txt` Disallow + `<meta name="robots" content="noindex">`。
- 卡片 JSON 内嵌页面，前端零框架。

### 6. 种子 + 首次运行
- `seeds/fomc-2026-09-16.json`：把底稿 12 条结论/2 条丢弃项/引用段落结构化，`seed` 命令写入库，署名「人工 + Claude Opus 5 辅助，2026-09-17」；流水线对同 URL 不重复生成。
- 跑 `run`：抓 11 个源 → Fed 近 15 条 + BLS 最新 + PBOC → 分级 → 生成解读 → 闸门 → 建站。

### 7. 部署 + 定时
- `gh repo create derek2035/newsdesk --public --source . --push`；`publish.py` 用 `git worktree` 把 `site/` 推到 `gh-pages`；`gh api` 开启 Pages（source=gh-pages）。站点地址 `https://derek2035.github.io/newsdesk/`。
- `scripts/run_daily.sh` + launchd plist（每日 07:30，`StartCalendarInterval`），失败用 `osascript` 通知 + 日志；任何一步失败不 push。
- 顺手修 `CLAUDE.md` 乱码（矻盾→矛盾、砎掉→砍掉、失贤→失败、釒额→金额、码掉→砍掉、471 行重复句）；写 `.plan/v1.md`、README、memory（项目仓库/站点地址/LLM 后端选择）。

## 验证

1. `pytest tests/` — 三个 L1 抓取器 golden file 通过。
2. `python -m newsdesk run --dry-run` 无异常；`generation_log` 显示每条解读的闸门通过/丢弃计数，目标引用校验通过率 > 80%（文档指标）。
3. 本地 `python -m http.server -d site` 用内置浏览器检查：首页有 FOMC 种子卡 + 流水线生成的事件；事件页悬停角标显示原文片段；归档页搜索「加息」能命中；AI 区块与事实区视觉分离。
4. `publish` 后 `curl -I https://derek2035.github.io/newsdesk/` 返回 200，页面 `noindex` 存在。
5. `launchctl load` 后 `launchctl list | grep newsdesk` 存在；手动 `launchctl start` 一次跑通。
